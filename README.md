# Homebrew Tap

Homebrew formulae for tools by [@rozd](https://github.com/rozd).

## Usage

```bash
brew tap rozd/tap
brew install iconkit
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| [iconkit](https://github.com/rozd/icon-kit) | CLI tool for working with Apple `.icon` bundles |
